The synthetic players

Each synthetic player is a simulated person with built-in memory and reaction-time traits. They learn real opening lines (from 3,865 Lichess lines), then practise them for 180 simulated days. Every session records whether they played the line without a mistake and how long they hesitated.

The Impulsive Blitzer

Moves fast and hesitates little even when unsure, but forgets quickly and blunders on neglected lines.

baseline 220 ms · effort β 0.4 · practice rate α 0.35 · decay C 0.65

The Balanced Learner

The average player: moderate speed, moderate effort, average forgetting.

baseline 300 ms · effort β 1.0 · practice rate α 0.25 · decay C 0.50

The Diligent Calculator

Slow and careful; thinks hard when memory fades, retains lines best.

baseline 380 ms · effort β 2.2 · practice rate α 0.20 · decay C 0.35

Each player gets slightly varied traits around their persona, plays white or black, and learns 15–40 lines.

What is predicted, and the loss function

Before every review the model predicts p, the chance the player gets through the whole line with no mistakes. Afterwards we know the outcome y: 1 if clean, 0 if they blundered.

p = R(t, S) = (1 + F · t / S) ^ (−w20) t = days since last review, S = memory stability of the line

Training minimises the log loss (binary cross-entropy). It punishes confident wrong predictions hardest:

L(w) = −(1/N) · Σ [ y·log(p) + (1−y)·log(1−p) ]

The weights w0…w20 control how stability grows or shrinks after each review. They were fitted by L-BFGS-B, kept within the official FSRS limits.

Takeaways

Training works. The trained weights cut the prediction error by about a fifth, and halve the distance to the players' true recall chance.

Default FSRS is too optimistic for chess lines (≈78% predicted vs ≈61% real), because a clean session needs every move right, which is harder than one flashcard.

Limits. All players are synthetic, so nothing here has been checked on real people yet. The review planner (which line to practise next) is not trained yet.
