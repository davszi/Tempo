Dataset manifest: fsrs-memory
============================

The data is git-ignored. It lives under ml/data/fsrs-memory/ on the machine
that ran the experiment and is regenerated byte for byte from this
experiment's landing commit (no other input):

  cd ml
  python -m tempo_ml.simulator.generate --config configs/fsrs-memory.json --out data/fsrs-memory/train
  python -m tempo_ml.simulator.generate --config configs/fsrs-memory-holdout.json --out data/fsrs-memory/holdout

Each folder also holds the generator's full manifest.json (config, counts,
environment); the essentials are copied here. memory_weights.csv holds every
client's hidden FSRS-6 weights (evaluation only, like ground_truth.csv).
