Datasets of the 2026-11-16 move-recall experiment
==================================================

Not tracked in Git (ml/data/ is ignored). Whether to keep them outside Git is
the person's decision and is still open (SUMMARY.md, "Run output").
Locations: ml/data/move-recall/ on the ML owner's machine, and
~/tempo-move-recall/ml/data/move-recall/ on the TU Clausthal cluster
(cloud-201, user sc05). 17 MB in total.

Regenerate from ml/ with the experiment's code (see SUMMARY.md, Source):

  for s in 20261111 20261121 20261131; do
    python -m tempo_ml.simulator.generate --out data/move-recall/seed-$s/train   --config configs/fsrs-memory.json         --seed $s
    python -m tempo_ml.simulator.generate --out data/move-recall/seed-$s/holdout --config configs/fsrs-memory-holdout.json --seed $((s+1))
    python -m tempo_ml.simulator.generate --out data/move-recall/seed-$s/reduced --config configs/fsrs-memory.json         --seed $s --horizon-days 60
  done

Check: every file's SHA-256 below must match (the same hashes are in each
directory's manifest.json). Generated on the cluster (Linux, Python 3.13.3,
numpy 2.5.4) and regenerated byte for byte on macOS on 2026-11-16 (seed
20261111 train) and on 2026-11-17 after merging 7ef4fe7 (all nine).
