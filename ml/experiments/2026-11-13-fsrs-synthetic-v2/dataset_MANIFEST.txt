Dataset manifest: fsrs-synthetic-v2
====================================

The data is git-ignored. It lives under ml/data/fsrs-synthetic-v2/ on the
machine that ran the experiment and can be regenerated byte for byte.
Each folder also holds the generator's full manifest.json (config, counts,
environment); the essentials are copied here.

Producing code and catalog: commit 09f8a22 (its backend/tempo_demo.sqlite
has 91 families and 2,719 lines, before d2e5903 regrouped the families) plus
code.diff in this folder. Regenerate byte for byte (checked on 2026-11-13,
all eight CSVs identical):

  git worktree add --detach <dir> 09f8a22
  cd <dir> && git apply <this folder>/code.diff
  cd ml/ml_300bots/ml_engine
  PYTHONPATH=src python -m tempo_ml.synthetic_data.generate --out <out>/train --seed 20261111
  PYTHONPATH=src python -m tempo_ml.synthetic_data.generate --out <out>/holdout --seed 20261112 --clients-per-archetype 20

The same settings are in ml/configs/multiplicative-memory.json and
multiplicative-memory-holdout.json. The current code in ml/tempo_ml
(python -m tempo_ml.simulator.generate --config ...) reads the current
catalog, where every family is White or Black and side_in_games is gone, so
it produces different data from the same settings.
